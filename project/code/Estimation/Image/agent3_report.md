# Agent 3 独立多摄像头灯点去重融合报告

## 输入与边界

- 只读取 `C:/Users/23055/Downloads` 下三份指定原始 CSV。
- 只使用 `I0..I26`：三摄像头、每个摄像头 3 个槽位、每个槽位 `(x, y, size)`。
- `I27..I37` 被视为旧流程输出列，验证脚本和算法均不读取。
- 强制预处理：任意一个摄像头在单帧内有效灯点数大于该数据集标注灯数 `N`，整帧丢弃。

## 算法思路

1. 每帧先按 `(x, y, size)` 是否任一非零提取每个摄像头的有效槽位。
2. 执行过计数门控：只丢弃 `camera_count > N` 的帧；少检帧保留。
3. 每个摄像头内部按 `y` 降序、`size` 降序、`x` 升序稳定排序。
4. 第 `k` 个排序灯点跨摄像头合成第 `k` 个全局灯簇，完成多摄像头重复观测去重。
5. 对缺测的全局灯簇输出占位簇，`quality=0` 且 `members=synthetic_missing`。
6. 输出灯簇数量固定为标注 `N`；本版本不计算距离和角度。

## 原则说明

- KISS：算法只做计数门控、稳定排序、按序跨相机配对三件事。
- YAGNI：未加入距离、角度、历史滤波或工程现有模型。
- DRY：Python 验证脚本与 C 核心共享同一输入解释和排序规则。
- SOLID：C 版本将融合输入、输出和单帧处理封装为独立接口，不依赖工程既有算法。
