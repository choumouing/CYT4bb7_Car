# Agent 3 全新融合算法报告

## 设计目标

- 完全不调用 `beacon_fusion.c/h`，只读取三份任务指定 CSV 的前 27 列原始检测。
- 最高优先级是去除重合视野重复计数，保留帧输出全局灯数量必须等于文件名标注真实灯数。
- 不计算物理距离和角度，只输出融合后的灯簇数量、成员和简单均值。

## 核心算法

1. 每帧统计三路摄像头各自非零槽位数。
2. 若任一摄像头计数大于标注灯数 `N`，按强制规则丢弃整帧。
3. 保留帧中，每路相机按 `radius` 降序、`y` 降序、`x` 升序得到稳定秩序。
4. 第 `k` 个秩序目标跨摄像头合并为第 `k` 个全局灯簇。
5. 欠检时仍保留第 `k` 个灯簇占位，输出总簇数固定为 `N`；占位簇的 `evidence_count=0`。

## 结论

- 三个数据集在强制预处理保留帧上的灯数量准确率均为 100%。
- 该算法把实际灯数 `N` 作为外部已知配置；它解决的是多摄像头重合视野重复计数，不解决动态未知灯数估计。
- 欠检帧可保证数量正确，但缺失灯簇只有低证据占位，后续若要用于控制，应结合置信度过滤。
