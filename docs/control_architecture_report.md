# 麦克纳姆轮小车控制环架构报告

## 1. 系统概述

本项目基于 Infineon CYT4BB7 双核 Cortex-M7 MCU（实际使用 CM7_0 核心），驱动一台麦克纳姆轮四驱小车，用于红外信标灭火竞赛。程序采用分层架构，自底向上分为四层：

| 层级 | 目录 | 职责 |
|------|------|------|
| Common | `project/code/Common/` | 通用数学工具、滤波器基础组件 |
| HW_Drivers | `project/code/HW_Drivers/` | 硬件抽象：IMU、编码器、电机、UWB |
| Estimation | `project/code/Estimation/` | 传感器融合与状态估计 |
| Controller | `project/code/Controller/` | PID 控制器、级联控制环、模式状态机 |

依赖方向严格为 `Common ← HW_Drivers ← Estimation ← Controller`，状态估计层负责产生融合后的状态量，控制器层消费状态量并输出电机指令。

## 2. 主调度器与多速率循环

入口位于 `project/user/main_cm7_0.c`，通过 1 kHz PIT 定时器中断驱动，分频产生四个执行速率：

```c
car_platform_init();   // 250 MHz 时钟、调试串口
car_loop_init();       // 初始化所有模块，启动 1 kHz PIT
while(true) {
    car_loop_poll();   // 超级循环调度器
}
```

| 频率 | 触发方式 | 执行任务 |
|------|----------|----------|
| **1000 Hz** | PIT 中断直接置位 | IMU 读取 → 加速度计校准 → 滤波链 → Mahony AHRS → 欧拉角输出 |
| **100 Hz** | PIT 计数分频 | 编码器更新、里程计融合、速度 PID 内环、摄像头 SPI 轮询、信标检测、菜单刷新 |
| **50 Hz** | PIT 计数分频 | 偏航角速率 PID 中环 |
| **25 Hz** | PIT 计数分频 | UWB 更新、SBUS 解析、无线控制、启停状态机、模式调度、偏航角保持（外环） |
| **Idle** | 主循环空闲 | WiFi 轮询、摄像头 SPI 完成处理、机间通信轮询 |

## 3. 状态估计管线

状态估计为控制环提供准确的反馈量，从传感器原始数据到可用的位姿估计，经历三级处理。

### 3.1 IMU 姿态估计（1 kHz）

这是整个控制系统的最高频环路，也是偏航角速率内环的反馈来源。

**传感器**：ICM42688 六轴 IMU，通过 SPI 以 10 MHz 通信，输出陀螺仪（dps）和加速度计（g）。

**信号调理**：原始数据经过 IIR 二阶 Biquad 滤波链（`IMU_Filtter.c`），采用转置直接 II 型结构：

```
陀螺仪链（3 轴 × 4 级 = 12 个 Biquad）：
  抗混叠 LPF(250Hz Butterworth) → 陷波(161Hz, Q=8.05) → 陷波(320Hz, Q=16) → LPF(60Hz Butterworth)

加速度计链（3 轴 × 3 级 = 9 个 Biquad）：
  陷波(161Hz, Q=8.05) → 陷波(320Hz, Q=16) → LPF(12Hz Butterworth)
```

陷波器用于抑制电机和结构共振产生的特定频率噪声（161 Hz 和 320 Hz）。

**姿态估计**：Mahony 互补滤波器（`MahonyAhrs.c`），与 INAV 飞控的 6 轴算法对齐。

- 状态量：四元数 (q0, q1, q2, q3)
- 核心机制：陀螺仪积分 + 加速度计叉积误差反馈校正
- 自适应信任权重：仅在加速度模值接近 1g（线性信任带 ±0.35g）时才使用加速度计校正
- 静态检测：陀螺 < 1.5 dps 且加速度模值在 1g ±0.08g 内连续 100 次采样
- Z 轴陀螺死区：0.2 dps，抑制偏航漂移
- 参数：Kp = 1.0，Ki = 0.0（积分未启用）
- 输出：`g_euler`（roll、pitch、yaw，单位度），同时通过 `g_imufilter_1000hz.gyroz` 输出滤波后的角速率供角速率环使用

### 3.2 编码器-惯性里程计融合（100 Hz）

为 MODE_1/2 的位置闭环提供前进/横移位置和速度估计。

**编码器处理**：4 路正交编码器各自经过一维标量卡尔曼滤波平滑（`encoder_control.c`）：

```
过程噪声 Q = 0.25，测量噪声 R = 4.0，初始误差协方差 P = 1.0
卡尔曼增益 K = P / (P + R)
估计值 += K × (测量值 - 估计值)
P = (1 - K) × P
```

**运动学解算**：通过麦克纳姆轮逆运动学将四轮速度分解为前进速度和横移速度。

**自适应互补滤波融合**（`odometer.c`）：

```
预测值 = 上一速度 + 校正后体轴加速度 × dt
融合值 = α × 预测值 + (1 - α) × 编码器速度
```

动态权重 α 由以下风险指标综合计算：
- 速度幅值（高速时更信任编码器）
- 加速度-编码器残差（分歧大时降低加速度信任）
- 换向检测（方向反转时降低加速度信任）
- 偏航率（高偏航时降低信任）
- 双轴运动（对角行驶时降低信任）

融合后的体轴速度通过 `g_euler.yaw` 投影到全局坐标系，积分得到 `g_odometer`（前进距离、横移距离、总行程）。

### 3.3 UWB 定位（25 Hz）

为 MODE_1/2 提供全局位置反馈。

**传感器**：ALX_AOA UWB 通过 UART 通信，输出距离、方位角和俯仰角。

**滤波管线**（`ALX_AOA.c`）：

```
球坐标 → 笛卡尔坐标 (x, y)
  → 3 元素滑动中值滤波（预滤波去脉冲）
  → Alpha-Beta 跟踪器（α=0.40, β=0.020）
```

Alpha-Beta 跟踪器同时提供位置和速度估计。包含观测门控异常值剔除机制：当观测值与预测值偏差超过阈值时拒绝该观测，并对速度施加衰减。

## 4. 控制架构（级联 PID）

### 4.1 PID 控制器类型

项目实现两种 PID 控制器（`pid.c`）：

| 类型 | 用途 | 特点 |
|------|------|------|
| **位置式 PID（PositionalPID）** | 偏航角环、偏航角速率环 | 含非线性二次 P 项：`kp_2 × err² + kp_1 × err`，积分抗饱和，输出限幅 |
| **增量式 PID（IncrementPID）** | 四轮速度环 | 经典增量式：累积 `kp×Δerr + ki×err + kd×Δ²err`，输出限幅 |

### 4.2 级联控制数据流

这是整个系统的核心——一个三级串联的偏航控制环，从外环到内环依次为：

```
┌─────────────────────────────────────────────────────────────────┐
│  外环 @25Hz：偏航角保持环                                       │
│  ┌──────────────────────────────────────────────────┐           │
│  │ control_yaw_hold_update_25HZ()                    │           │
│  │   输入：偏航角目标 (rad) vs 当前 yaw (g_euler → rad) │         │
│  │   控制器：PositionalPID (yaw_angle_pid)            │           │
│  │   输出：偏航角速率目标 (rad/s)                      │           │
│  └──────────────────────┬───────────────────────────┘           │
│                         ↓                                       │
│  中环 @50Hz：偏航角速率环                                       │
│  ┌──────────────────────────────────────────────────┐           │
│  │ control_yaw_rate_loop_update_50HZ()               │           │
│  │   输入：角速率目标 vs 滤波后陀螺 Z 轴 (g_imufilter) │          │
│  │   控制器：PositionalPID (yaw_rate_pid)             │           │
│  │   输出：旋转补偿分量 (encoder-count 单位)           │           │
│  └──────────────────────┬───────────────────────────┘           │
│                         ↓                                       │
│  内环 @100Hz：四轮速度环                                        │
│  ┌──────────────────────────────────────────────────┐           │
│  │ control_cascade_speed_loop_update_100HZ()         │           │
│  │   麦克纳姆轮运动学分解：                            │           │
│  │     LF = forward - strafe - rotate                │           │
│  │     RF = forward + strafe + rotate                │           │
│  │     LR = forward + strafe - rotate                │           │
│  │     RR = forward - strafe + rotate                │           │
│  │   控制器：4× IncrementPID (每轮一个)               │           │
│  │   反馈：卡尔曼滤波后编码器速度                      │           │
│  │   输出：PWM 占空比 → mecanum_motor_set_all()      │           │
│  └──────────────────────────────────────────────────┘           │
└─────────────────────────────────────────────────────────────────┘
```

**关键设计**：

- **外环慢于内环**：偏航角环 25 Hz、角速率环 50 Hz、速度环 100 Hz。内环比外环快 4 倍，保证内环在外环输出变化前已经收敛。
- **航向锁定**：当用户摇杆旋转输入为 0（`rotate_target == 0`）时，系统自动捕获当前航向角作为偏航角环的设定值，实现"松手自锁航向"。
- **直接旋转模式**：当有旋转输入时，直接使用偏航角速率环，跳过偏航角外环。

### 4.3 位置控制环（MODE_1/2 专用）

在 MODE_1/2 下，外层还有一个位置控制环叠加在上述级联 PID 之上：

```
UWB 位置 (alx_aoa_x/y) ──┐
                           ↓
                    位置误差计算
                           ↓
              PositionalPID (X/Y 各一个)
                           ↓
                    forward_target / strafe_target
                           ↓
              ┌─── 进入级联 PID 管线 ───┐
              ↓                          ↓
         偏航角环 → 角速率环 → 速度环 → 电机
```

## 5. 控制模式与安全机制

### 5.1 启停状态机（`car_start_sbus.c`）

```
INIT ──→ STANDBY ──→ RUNNING
                      │
            CH5 关闭 / 遥控离线 / CH6 中位
                      │
                      ↓
                   STANDBY（所有输出清零，PIDs 全部复位）
```

STANDBY → RUNNING 需同时满足：遥控器 CH5 = DOWN（使能）且 CH6 模式有效。

### 5.2 运行模式

| 模式 | 名称 | 数据流 |
|------|------|--------|
| **MODE_0** | 手动遥控 | SBUS 摇杆 → `wireless_control` → forward/strafe/rotate → 级联 PID → 电机 |
| **MODE_1/2** | UWB 跟随/目标导航 | UWB 位置 → 位置 PID → forward/strafe → 级联 PID → 电机 |

MODE_2 内部子状态机：

```
FOLLOW_TAG ──→ GOTO_TARGET ──→ TARGET_REACHED
     ↑              │                │
     └──────────────┴────────────────┘
           （进入标签范围内切换，到达后选择下一个目标点）
```

### 5.3 遥控器输入链路

```
SBUS 接收器 (UART)
  → sbus_update_25HZ()              // 原始通道解析，在线检测
  → wireless_control_update_25HZ()  // 通道映射为控制指令
      CH1: 横移 (strafe)
      CH2: 前进 (forward)
      CH4: 旋转 (rotate)
      CH5: 使能开关
      CH6: 模式选择（上=手动, 下=UWB跟随）
  → car_start_sbus_update_25HZ()    // 启停状态机 + 模式选择
  → car_mode_update_25HZ()          // 模式分发
```

## 6. 滤波器汇总

| 滤波器 | 类型 | 应用位置 | 关键参数 | 文件 |
|--------|------|----------|----------|------|
| IIR Biquad Butterworth LPF | 二阶低通 | IMU 陀螺/加速度计信号调理 | 250/60/12 Hz | `IMU_Filtter.c` |
| IIR Biquad 陷波滤波器 | 二阶带阻 | IMU 抑制电机共振噪声 | 161 Hz (Q=8.05), 320 Hz (Q=16) | `IMU_Filtter.c` |
| 一维卡尔曼滤波 | 最优估计 | 编码器计数平滑 | Q=0.25, R=4.0 | `encoder_control.c` |
| Alpha-Beta 跟踪器 | 常增益跟踪 | UWB 位置跟踪 | α=0.40, β=0.020 | `ALX_AOA.c` |
| Mahony 互补滤波 | 传感器融合 | 陀螺+加速度计姿态估计 | Kp=1.0, Ki=0.0 | `MahonyAhrs.c` |
| 自适应互补滤波 | 传感器融合 | 编码器+加速度计速度估计 | 动态 α（风险自适应） | `odometer.c` |
| 一阶低通 (PT1) | 通用滤波 | 加速度计偏置、通用信号 | τ 参数化 | `car_filter.c` |
| 3 元素中值滤波 | 非线性滤波 | UWB 位置预滤波 | 窗口=3 | `car_filter.c` |
